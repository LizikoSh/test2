4GARMIN — ОФЛАЙН ІНТЕРАКТИВНИЙ КОНТЕНТ-ПЛАН v3

НОВЕ:
- клік по аватарці 4Garmin у верхній частині профілю відкриває Stories;
- Stories можна гортати кнопками/кліком ліворуч-праворуч або стрілками клавіатури;
- є прогрес-бари, квізи, опитування, питання та переходи до пов’язаних дописів;
- усі Stories оформлені як фінальні 9:16 макети;
- пов’язані дописи відкриваються прямо зі Stories;
- усе працює без Інтернету.

ЯК ВІДКРИТИ:
1. Розпакуйте ZIP.
2. Відкрийте index.html.
3. Натисніть на аватарку вгорі — перегляд Stories.
4. Натисніть на обкладинку в сітці — перегляд допису.

КЕРУВАННЯ STORIES:
- права частина Story / стрілка → наступна;
- ліва частина / стрілка ← попередня;
- Esc — закрити;
- у квізах і опитуваннях можна натискати варіанти.
