# 4Garmin — адаптивний макет головної сторінки

Самодостатній адаптивний HTML-макет. Логотип і зображення вбудовані в `index.html`, тому окрема папка з ресурсами не потрібна.

Макет оптимізовано для широких десктопів, ноутбуків, планшетів і смартфонів
від 320 px. На мобільних секції перебудовуються в одну колонку, картки
залишаються читабельними, а смуга переваг підтримує горизонтальний свайп.

## Як опублікувати через GitHub Pages

1. Створіть новий репозиторій на GitHub.
2. Завантажте **вміст** цієї папки в корінь репозиторію.
3. Відкрийте `Settings` → `Pages`.
4. У `Build and deployment` виберіть `Deploy from a branch`.
5. Виберіть гілку `main`, папку `/ (root)` і натисніть `Save`.

Після публікації GitHub відкриватиме `index.html` автоматично.

> Це дизайн-макет: кнопки й посилання демонстраційні та наразі не підключені до каталогу Хорошоп.
